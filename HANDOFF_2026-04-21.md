## What changed (Flutter-facing)

### 1. B7 UL safety banner now renders

Products like multi-form Vitamin A multivitamins now show a safety banner when the **summed** dose across forms exceeds the UL. Example: "Vitamin A exceeds UL (200%) — summed across 2 forms."

- `score_breakdown_card.dart` — evidence renderer was reading wrong keys (`ingredient`/`reason` instead of `nutrient`/`amount`/`ul`/`pct_ul`). Fixed.
- D4.3 canonical-sum aggregation lights up on 1,929 products in the new catalog. This is the teratogenicity-protection path (Rothman 1995 NEJM).

### 2. `warnings_profile_gated` now renders

Previously `_parseWarnings` only read `blob['warnings']` — the pipeline also emits `blob['warnings_profile_gated']` for profile-conditional Dr Pham copy (e.g., Titanium Dioxide EU-ban alert for pregnancy). These warnings carry `condition_id` / `drug_class_id` and are filtered by `matchesProfile()` in `product_detail_screen.dart`. Now piped through correctly.

### 3. `InteractionWarning` model extended — **10 new fields available**

`InteractionWarning.fromJson` now parses everything the pipeline emits. Use these in widgets if you want richer detail sheets:

| Field | Source | Typical use |
|---|---|---|
| `clinicalRisk` | banned_recalled / high_risk_ingredient | Banner tint (critical/high/moderate/low) |
| `mechanismOfHarm` | harmful_additive | Technical detail sheet |
| `populationWarnings` | harmful_additive | At-risk groups bullet list |
| `doseThresholdEvaluation` | interaction / drug_interaction | Trigger-dose context ("only at >500 mg/day") |
| `regulatoryDate` + `regulatoryDateLabel` | banned_recalled | "First EU ban: 2022-08" |
| `additiveCategory` | harmful_additive | "colorant", "sweetener", etc. |
| `allergenPrevalence` | allergen | "high" / "moderate" / "low" |
| `supplementContext` | allergen | "Common emulsifier in soft-gels" |
| `identifiers` | all types | `{cui, unii, cas, pubchem_cid}` |

Tests added: `test/features/product_detail/interaction_warnings_test.dart` — 5 new tests covering each warning type.

### 4. Dr Pham's copy now surfaces for all banned entries

The pipeline's `_check_banned_substances` wasn't propagating `safety_warning` / `safety_warning_one_liner` / `ban_context` through to the detail blob. Fixed on the pipeline side. All 2,413 banned-entry warnings now carry Dr Pham's layperson copy, which flows into `alertHeadline` / `alertBody` via the existing `fromJson` fallback chain.

**Before:** banned warnings showed only technical `title` + `detail`.
**After:** banned warnings show layperson one-liner + full Dr Pham body.
