# PharmaGuide Core Rules

- Preserve deterministic logic.
- Prefer minimal diffs over broad rewrites.
- Never invent health claims, contraindications, evidence, or scoring behavior.
- Separate UI, domain logic, storage, and network concerns.
- Inspect relevant files before editing.
- Do not rewrite unrelated code.
- After implementation, run the smallest relevant verification command.
- If unsure, stop and report uncertainty instead of guessing.
