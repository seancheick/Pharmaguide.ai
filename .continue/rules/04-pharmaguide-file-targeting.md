# File Targeting Rules

Before editing:
- List the files you need
- Explain why each file matters
- Confirm whether new files are needed

During editing:
- Touch the minimum number of files possible
- Avoid formatting or reordering unrelated code
- Keep public interfaces stable unless the task explicitly requires a change

After editing:
- Summarize exactly which files changed
- Explain what changed in each file
- State whether any planned files were not touched
