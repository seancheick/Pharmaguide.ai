## Key Patterns to Know

### Test Pattern (CRITICAL — read lessons-learned.md)
```dart
// NEVER use pumpAndSettle() with async Drift providers
// NEVER use setUp/tearDown for DB lifecycle
// ALWAYS:
final coreDb = CoreDatabase.memory();
final userDb = UserDatabase.memory();
// ... ProviderScope overrides ...
await tester.pump();
await tester.pump(const Duration(milliseconds: 100));
// ... test assertions ...
await tester.pumpWidget(const SizedBox.shrink());
await coreDb.close();
await userDb.close();
```

### Architecture Quick Reference
- **Two repos:** `dsld_clean` (pipeline, Python) + `PharmaGuide ai` (Flutter app)
- **Bridge:** Pipeline → `pharmaguide_core.db` + `interaction_db.sqlite` → bundled in Flutter assets via Git LFS
- **Providers:** `coreDatabaseProvider`, `userDatabaseProvider`, `interactionDatabaseProvider` — all must be overridden in `main.dart` and in test `ProviderScope`
- **PHI rule:** Medications (`type='medication'`) NEVER sync to Supabase. Grep test enforces this.
- **Detail blobs:** In Supabase Storage, NOT in bundled DB. Fetch via `DetailBlobService.fetchDetailBlobByHash`
